## 📱 About PhoneHunter

PhoneHunter is a simple, responsive, and interactive phone finding website that allows users to search for smartphones, view detailed specifications, and explore the latest mobile devices. Built with HTML, CSS, and JavaScript, this project demonstrates modern web development practices with an intuitive user interface and seamless API integration.

### ✨ Features
- 🔍 Search phones by name or brand
- 📊 View detailed phone specifications
- 💻 Fully responsive design for all devices
- ⚡ Fast and interactive user experience
- 🎨 Clean and modern UI

---

## 🔌 APIs Used

### Phone Search API

Retrieve a list of phones based on search query.

| Property | Details |
|----------|---------|
| **Method** | GET |
| **URL Format** | `https://openapi.programming-hero.com/api/phones?search=${searchText}` |
| **Example** | `https://openapi.programming-hero.com/api/phones?search=iphone` |

### Single Phone API

Get detailed information about a specific phone.

| Property | Details |
|----------|---------|
| **Method** | GET |
| **URL Format** | `https://openapi.programming-hero.com/api/phone/${id}` |
| **Example** | `https://openapi.programming-hero.com/api/phone/apple_iphone_13_pro_max-11089` |
